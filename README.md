# Гибнущий мир

2D souls-like в умирающем мире. pygame-ce, Python 3.12. Вся графика и звук
генерируются процедурно: в репозитории нет ни одного ассета.

Три уровня демо:

1. **Гибнущие топи** (`swamp`) — пробуждение, Пожиратель.
2. **Выжженное стекло** (`glass`) — Близнецы, острые грани стекла.
3. **Немой колодец** (`well`) — вертикальный спуск, Слепой смотритель.

## Запуск

```sh
python3.12 -m venv .venv
.venv/bin/pip install -e . pytest
.venv/bin/slg
```

Если установлен `uv`:

```sh
uv sync
.venv/bin/slg
```

Полезные флаги:

```sh
.venv/bin/slg --level 2          # начать со второго уровня
.venv/bin/slg --level 1 --debug  # PageUp/PageDown переключают уровни
.venv/bin/slg --edit --level 3   # редактор уровня
```

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D` | движение |
| `Space` | прыжок (высота зависит от удержания) |
| `Shift` / `L` | перекат с i-frames |
| `J` | быстрый удар |
| `K` | тяжёлый удар |
| `Q` | лечение (заряды фляги) |
| `E` | чекпоинт / переход на следующий уровень после победы |
| `Esc` | пауза |
| `M` | вкл/выкл эмбиент |
| `PageUp` / `PageDown` | смена уровня в режиме `--debug` |

## Редактор уровней

```sh
.venv/bin/slg --edit --level 2
```

- `WASD` / стрелки или средняя кнопка мыши — панорама.
- ЛКМ — выбрать и перетащить, за ручки — изменить размер.
- `Shift` + ЛКМ по пустому месту — добавить платформу, ПКМ — удалить.
- `1`/`2`/`3`/`0` — враги, `4` — чекпоинт, `5`/`6`/`9` — боссы,
  `7`/`8` — триггер арены / ворота, `E` — спавн игрока.
- `N` — `organic`, `H` — `sharp`, `Delete` — удалить выбранное.
- `F1` — помощь, `F2` / `Ctrl+S` — сохранить, `F5` — перечитать с диска.

## Тесты

```sh
.venv/bin/python -m pytest -q
```

Тесты полностью headless: ядро не импортирует pygame, а рендер и аудио
проверяются под SDL dummy.

## Структура

```
src/slg/
  main.py            окно, ввод, игровой цикл
  editor.py          редактор уровней
  core/              симуляция без pygame
    session.py       оркестратор
    player.py        FSM игрока
    enemies.py       враги и снаряды
    boss.py          базовый босс
    keeper.py        финальный босс колодца
    physics.py       гравитация и коллизии
    combat.py        бой, stamina, poise, i-frames
    level.py         загрузка уровней
    world.py         сущности и платформы
    config.py        весь баланс
  render/            камера, фон, террейн, персонажи, HUD, палитра
  audio/             процедурный звук
  data/              JSON-уровни
tests/               pytest
docs/                архитектура, тесты, добавление контента
```
